# Dashboard

index.html (en), index.ko.html, index.zh-CN.html are generated by tools/build_i18n.py from one source + i18n/{en,zh-CN}.json

- The page reads its data from the folder it sits in: `wbs.csv` (required), `coverage.csv`, `plan.csv`, `events.csv` and `digest_<year>.csv` when present. English and Korean headers and values are both accepted (schema v6, see the main README).
- Copy the page next to a ledger and serve the folder over HTTP (`python3 -m http.server -d <folder>`) or publish it as an artifact; browsers may block reading the CSV files from a page opened directly from disk.
- The sample ledgers in `sample/en` and `sample/ko` have the reference date 2026-11-06.
- Answers from the Status check mode can be written back with `scripts/reconcile.py apply <folder> answers.json` (a list of `{"year", "code", "status", "end", "blocker"}` objects).
